# Privacy Policy

Last updated: 2026-09-16

GitHub Diff Defaults does not collect, sell, or transmit personal data.

The extension stores two Boolean preferences in Chrome Sync: whether to hide
whitespace-only changes and whether to hide files marked as viewed. It also
reads the URL of the currently opened GitHub page locally to determine whether
it is a pull-request Changes page. URLs are not stored or transmitted.

These preferences are used only to modify the URL of GitHub pull-request
Changes pages in the user's browser. The extension does not use analytics,
remote servers, cookies, or third-party services.

For questions about this policy, open an issue in this repository.
